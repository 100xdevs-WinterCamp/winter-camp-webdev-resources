## Run the async assignment tests

From the repository root:

```bash
cd Day-01/02-Afternoon/Assignments/01-async-js
npm ci
npm test
```

Read the exercise instructions, implement the TODOs, and rerun the relevant tests. Starter tests can fail until you complete the exercises. Each assignment package has its own scripts; see its `package.json` and README.
