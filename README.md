## Getting started

1. Clone this repository:

   ```bash
   git clone https://github.com/100xdevs-WinterCamp/winter-camp-webdev-resources.git
   cd winter-camp-webdev-resources
   ```

2. Open a day, choose Morning or Afternoon, and follow its README.
3. Read the slides or notes, explore the class code, then work through the assignments.

Use Node.js 22 or newer and npm for the Node projects. Install dependencies inside the individual project folder. Day 2 afternoon also needs MongoDB; its README explains the setup.

## What is included

- GitHub repositories and the GitHub gist are copied into this repository as regular files. No submodules or separate clones are needed.
- Slides, Notion pages, and the interactive playground remain links to the original resources.
- Classroom code and unfinished assignment files retain their teaching context. See each session README for run instructions and known limitations.
- The Fundamentals/Prerequisites course folder is excluded.

Resources reflect the Web Dev course attachments available on **22 October 2026**. Follow the [course page](https://100xdevs.com/new-courses/winter-camp-2026-online/content?parentId=f_b9a89e6f-7a72-44a0-bb9e-aef3643c352d) for class recordings and newly added sessions.
